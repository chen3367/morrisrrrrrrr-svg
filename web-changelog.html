網站功能更新

GitHub Pages 變更紀錄

每筆更新都對齊 GitHub commit hash；遊戲資料版本變動請查看遊戲更新日誌。

31 筆更新

a70146c 橡皮擦道具圖示與來源

  • 木妖、蘑菇王、猴子、大幽靈、綠水靈、三眼章魚橡皮擦補上本地圖示。
  • 橡皮擦道具新增「轉蛋取得」來源。
  • 道具詳情頁移除怪物掉落、任務獲取、商人購買、合成取得的數量統計卡，讓來源區塊更乾淨。

d5a6039 戰鬥分析分享圖

  • 戰鬥分析新增分享圖產生與下載，可輸出玩家等級、職業、所在地圖，以及 10 分鐘平均 EXP / 楓幣收入。
  • 分享圖會讀取左上角小地圖名稱，並使用該地圖常見怪物作為右側背景；辨識不準時可手動修正地圖名稱。
  • 分享圖支援黑底與白底輸出，戰鬥分析也改為可從道具欄四個角落偵測楓幣。

ba5eb93 轉蛋活動資料更新

  • 皇家美容院與閃亮彗星更新到 2026/08/13 檔期，包含官方獎池、機率與楓葉點數預設價格。
  • 璀璨彗星保留為閃亮彗星碎片兌換與自動開啟的子池，不再作為可直接選擇的轉蛋商品。
  • 皇家美容院獎項使用正面紙娃娃預覽；缺少紙娃娃素材的項目會退回本地道具圖示。

37f4883 轉蛋獎項圖示

  • 轉蛋模擬器的皇家美容院、閃亮彗星與璀璨彗星獎項補上本地道具圖示。
  • 抽取紀錄、目標獎項選擇與獎池表格都會顯示獎項圖片，方便辨識抽到的物品。

8cb62b5 戰鬥分析等級辨識修正

  • 戰鬥分析改用遊戲本地素材中的 LV 數字樣板辨識等級。
  • 等級辨識只比對 LV 徽章內的白色數字筆畫，降低橘色底框或其他畫面元素造成的誤判。
  • 移除容易亂猜的全區域等級備援，避免出現 111 這類不合理等級。

7336efd 妖精艾溫合成來源補正

  • 月石、星石、黑羽毛補上魔法森林 NPC 妖精艾溫的任務解鎖合成來源，並標示需完成「艾溫的玻璃鞋」。
  • 修正月石、星石在 NPC 冶煉來源中的材料顯示，改為各類已冶煉礦石或寶石各 1 個。
  • 黑羽毛顯示火焰羽毛、月石、黑水晶與楓幣費用。

ed54b95 道具取得來源補正

  • 月石、星石補上伯堅與派伊的 NPC 合成來源，並顯示對應合成費用。
  • 狼牙恢復後街吉姆 NPC 合成來源。
  • 白色藥水、烤鰻魚、礦泉水、西瓜補上珍的任務解鎖商店來源與價格。

db57138 道具詳情頁連結修正

  • 修正部分道具詳情頁無法正常開啟的問題，包含名稱帶有 % 的卷軸。
  • 直接連到被篩選條件隱藏的道具時，仍會保留並顯示該道具詳情。

e62b0ea 轉蛋模擬器與工具頁調整

  • 新增「轉蛋模擬器」，可切換皇家美容院與閃亮彗星，設定抽獎間隔、目標獎項與自動打開璀璨彗星。
  • 皇家美容美髮依券種與角色性別切換獎池；抽取紀錄會逐抽顯示，B 等級以上獎項以醒目格式標示。
  • 實用工具頁的工具設定統一移到左側欄底部，並修正轉蛋模擬器手機版內容切換。

0f15750 戰鬥分析 OCR 判讀修正

  • 戰鬥分析改用像素模板判讀 EXP 小字，降低百分比與目前 EXP 被誤讀的情況。
  • LV 欄位新增橘色等級徽章專用辨識，改善不同解析度下等級無法正確讀取的問題。

5c6ea86 戰鬥分析累計統計與離群值排除

  • 戰鬥分析改為顯示累計每分鐘、累計10分鐘、總累計，以及預估10分鐘、預估30分鐘、預估升等所需時間。
  • EXP 與楓幣統計會排除負值、短時間巨大跳點與遠高於常態的離群區間，降低 OCR 誤判對平均值的影響。

678d57f 戰鬥分析視窗外框補償

  • 戰鬥分析偵測到像 1936x1119 這類包含 Windows 視窗外框的尺寸時，會自動校正為內層 1920x1080 遊戲畫面再擷取 LV、EXP 與楓幣。
  • 辨識狀態文字會提示目前是否已避開視窗外框，方便確認螢幕分享抓到的是遊戲內容還是整個視窗。

546c8e3 戰鬥分析 EXP 判讀修正

  • 戰鬥分析新增 LV 辨識區塊，並改用像素模板判讀 EXP 與楓幣，降低小字 OCR 誤讀造成無法加入紀錄的情況。
  • EXP 百分比改由已讀到的等級與 EXP 依經驗表計算，不再用 EXP 與百分比反推等級。

495e980 戰鬥分析解析度選擇

  • 戰鬥分析新增「辨識解析度」選單，可手動固定 1366x768、1920x1080、2560x1440、2732x1440 或 3840x2160 的 OCR 校正區塊。
  • 解析度選擇會自動記住，避免螢幕分享或縮放造成辨識區塊誤判。

34da460 戰鬥分析辨識校正

  • 戰鬥分析改用依解析度校正的 EXP 與楓幣辨識區塊，涵蓋 1366x768、1920x1080、2560x1440、2732x1440、3840x2160。
  • 新增楓幣偵測提示，提醒先開啟道具欄並移到畫面右上角對齊。

10d1554 戰鬥分析工具

  • 新增「戰鬥分析」頁面，取代原本的等級經驗表入口。
  • 可透過分享螢幕讀取遊戲畫面的 EXP、百分比與楓幣，估算每分鐘、每 10 分鐘、每小時收益。
  • 新增升到下一級所需時間估算，並將等級經驗表整合為同頁折疊欄位。

9a0cec4 本地圖示替換

  • 依照已審核結果，將多個技能與 NPC 圖示替換為遊戲檔案內抽出的本地素材。
  • 角色立繪與楓幣圖示維持目前外部/手動素材來源。

a0037c4 圖示與文字修正

  • 「激勵」技能圖示改回本地遊戲素材抽出的圖示。

59b2632 手機版與戰鬥力計算機

eecff4d 戰鬥力計算機
