網站功能更新

GitHub Pages 變更紀錄

每筆更新都對齊 GitHub commit hash；遊戲資料版本變動請查看遊戲更新日誌。

22 筆更新

0f15750 戰鬥分析 OCR 判讀修正

  • 戰鬥分析改用像素模板判讀 EXP 小字，降低百分比與目前 EXP 被誤讀的情況。
  • LV 欄位新增橘色等級徽章專用辨識，改善不同解析度下等級無法正確讀取的問題。

5c6ea86 戰鬥分析累計統計與離群值排除

  • 戰鬥分析改為顯示累計每分鐘、累計10分鐘、總累計，以及預估10分鐘、預估30分鐘、預估升等所需時間。
  • EXP 與楓幣統計會排除負值、短時間巨大跳點與遠高於常態的離群區間，降低 OCR 誤判對平均值的影響。

678d57f 戰鬥分析視窗外框補償

  • 戰鬥分析偵測到像 1936x1119 這類包含 Windows 視窗外框的尺寸時，會自動校正為內層 1920x1080 遊戲畫面再擷取 LV、EXP 與楓幣。
  • 辨識狀態文字會提示目前是否已避開視窗外框，方便確認螢幕分享抓到的是遊戲內容還是整個視窗。

546c8e3 戰鬥分析 EXP 判讀修正

  • 戰鬥分析新增 LV 辨識區塊，並改用像素模板判讀 EXP 與楓幣，降低小字 OCR 誤讀造成無法加入紀錄的情況。
  • EXP 百分比改由已讀到的等級與 EXP 依經驗表計算，不再用 EXP 與百分比反推等級。

495e980 戰鬥分析解析度選擇

  • 戰鬥分析新增「辨識解析度」選單，可手動固定 1366x768、1920x1080、2560x1440、2732x1440 或 3840x2160 的 OCR 校正區塊。
  • 解析度選擇會自動記住，避免螢幕分享或縮放造成辨識區塊誤判。

34da460 戰鬥分析辨識校正

  • 戰鬥分析改用依解析度校正的 EXP 與楓幣辨識區塊，涵蓋 1366x768、1920x1080、2560x1440、2732x1440、3840x2160。
  • 新增楓幣偵測提示，提醒先開啟道具欄並移到畫面右上角對齊。

10d1554 戰鬥分析工具

  • 新增「戰鬥分析」頁面，取代原本的等級經驗表入口。
  • 可透過分享螢幕讀取遊戲畫面的 EXP、百分比與楓幣，估算每分鐘、每 10 分鐘、每小時收益。
  • 新增升到下一級所需時間估算，並將等級經驗表整合為同頁折疊欄位。

9a0cec4 本地圖示替換

  • 依照已審核結果，將多個技能與 NPC 圖示替換為遊戲檔案內抽出的本地素材。
  • 角色立繪與楓幣圖示維持目前外部/手動素材來源。

a0037c4 圖示與文字修正

  • 「激勵」技能圖示改回本地遊戲素材抽出的圖示。
  • 修正「檸檬」道具說明為回復 150 MP。

59b2632 手機版與戰鬥力計算機

  • 改善手機版版面，降低小螢幕上需要 hover 或大量捲動的操作。
  • 戰鬥力計算機新增輸入記憶、BUFF 選擇整理與多個技能圖示修正。

eecff4d 戰鬥力計算機

  • 新增戰鬥力計算機，可依職業、武器、基本數值、追加數值、技能點數與 BUFF 試算表攻與技能傷害。
  • 加入冒險家職業立繪與四轉職業相關資料。

a68b040 導覽與工具頁

  • 上方導覽改成「楓葉圖鑑」「實用工具」「其他」分組。
  • 合併地圖與世界地圖頁面，並新增遊戲更新日誌與網頁更新日誌入口。
  • 卷軸強化模擬器加入裝備與卷軸篩選、成本試算與模擬分布。

6446b27 清除條件控制

  • 各主要頁面新增「清除條件」按鈕，讓搜尋、篩選和進階條件可以一次回到預設狀態。
  • 怪物頁的「清除進階條件」併入共用清除流程。

12ed675 GitHub Pages 部署流程

  • 調整 Pages 部署流程，降低發布後頁面未即時可用的機率。
  • 新增部署韌性檢查，讓更新網站時比較容易定位發布問題。

b82e420 遊戲更新日誌

  • 新增玩家可讀的遊戲更新日誌頁面。
  • 將資料 diff 轉成網頁內可展開/收合的內容，避免直接開 Markdown 造成亂碼。

02bde9c 遊戲資料 1.13.6

  • 網站資料更新至 MapleStory Classic 1.13.6。
  • 同步任務、道具、地圖、技能和圖示資產。

639a8cf 任務資訊卡調整

  • 任務資訊卡的「接續任務」移到資訊卡底部，閱讀順序更接近任務流程。

d95932c 地圖頁與世界地圖

  • 調整地圖資訊卡欄位順序，分開顯示跨地圖與同地圖傳送點。
  • 世界地圖支援子地圖顯示選項，並改善節點與地區代表圖示。

404b433 楓幣圖示

  • 怪物掉落楓幣、商店價格、製作費用加入對應楓幣圖示。

0546e20 活動怪物預設隱藏

  • 預設隱藏楓葉世界等活動專屬怪物，降低目前版本查詢時的干擾。

0a432e8 無來源重複道具整理

  • 預設隱藏重複且無取得來源的道具，讓道具列表更乾淨。

3b13e49 圖示補強流程

  • 新增以精準路徑補圖示的流程，降低怪物、道具、技能和 NPC 圖示誤配問題。
